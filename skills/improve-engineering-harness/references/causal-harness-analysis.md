# Causal harness analysis

The proximate model error is rarely enough.

Use the chain:

`task condition -> harness affordance/constraint -> agent decision -> missing feedback/gate -> consequence`

Ask:

1. What did the agent know at the decision point?
2. What could it inspect or execute?
3. Was the correct rule discoverable and unambiguous?
4. Was a deterministic result being delegated to probabilistic reasoning?
5. Did any checker accept `UNKNOWN` or stale evidence as success?
6. Did the environment hide the evidence needed to disambiguate?
7. Did overlapping skills or instructions create conflicting objectives?

Separate roles:

- `PRIMARY`: independently sufficient harness mechanism.
- `CONTRIBUTING`: increases probability/severity.
- `LATENT`: dormant condition exposed by this case.
- `CONSEQUENCE`: downstream symptom, not a remediation target.

A proposed remediation should interrupt the causal chain at the earliest reliable, proportionate point.
